# Huni 0.9.2 — A more personal Huni

This Huni update establishes the Huni identity across the app and its public source. Playback, library, account, integrations, and settings continue to use the existing app functionality.

## What changed
- Applied Huni's dark-green palette and rounded design language across the home experience and shared components.
- Refined the home toolbar with the Huni logo and kept its existing actions available.
- Updated About with Huni branding, Remy Camiguel, and Huni-owned repository and license links; removed the Discord/About link.
- Replaced upstream release notes in the in-app Changelog with Huni-authored content.
- Pointed app release links and update checks to Huni.app.
- Added the Huni logo and Huni project/build information to the README.

## Compatibility
Existing playback, library, account, integrations, settings, data, and service behavior are preserved. Source notices and GPL-3.0 licensing remain intact.
