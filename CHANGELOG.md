## Unreleased

## v0.9.7 (2026-11-13)

### 🚀 Added
- Added the opt-in Match app icon to color setting, with palette-specific adaptive and monochrome launcher icons for all ten themes.
- Added a local redacted crash-report flow with explicit consent, preview, and user-controlled sharing or dismissal.
- Added an offline in-app Changelog backed by the bundled Markdown file.
- Synced the bundled in-app Changelog with the v0.9.7 release notes.

### 🎨 Changed
- Unified section headers and screen titles with adaptive sizing, and aligned Home card titles, muted subtitles, and mini-player presentation.
- Restyled the in-app Changelog and Updater release notes with emoji section labels and a project-wide bug-report link.
- Refined About layout and upstream credits, and added a Report a bug link.
- Separated Privacy crash-report controls, clarified confirmations, and standardized switch visibility.
- Reworked Android Auto section instructions, cards, drag handles, and toggles.
- Updated Appearance labels, palette interaction, refresh-rate copy, and themed-icon guidance.
- Updated contributor guidance for shared UI components and palette icon generation.

## v0.9.6 (2026-11-10)

- Configured themed monochrome icon resources for Android 13 and newer.
- Removed the misleading in-app toggle; themed icons are controlled by the Android launcher.
